== Description ==
This plugin syncs WooCommerce orders with Zoho API by sending order details when an order is placed or completed.

== Installation ==
1. Upload the `zoho-order-sync` plugin folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
